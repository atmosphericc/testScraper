# Claims ledger

Every number that drives a bot change lives here with the script that produces it, so
anyone (a person, or a fresh-context agent that has read nothing else) can re-derive it
with one command. **Nothing is armed in `run_bot_with_nightly_restart.bat` on a claim
below VERIFIED, and every arming REM cites the claim IDs it rests on.** A refuted claim
stays here marked REFUTED so it can never be cited again.

Scripts: `tools/analysis/` (read-only parsers over `logs/runs/*.log`; never touch the bot).

## Status ladder

| status | meaning |
|---|---|
| MEASURED | one analyst, one context, ad-hoc script. Not enough to arm anything. |
| REPRODUCED | the number comes out of a committed `tools/analysis/` script, run by the author. |
| VERIFIED | an independent fresh-context re-derivation (own parser, told to refute) agrees within stated tolerance. |
| LIVE-CONFIRMED / LIVE-REFUTED | the next drop's pre-registered readout (`tools/analysis/readout_*.py`) judged it. |
| REFUTED | shown wrong; keep the row, never cite. |
| WEAKENED | verifier found the effect smaller or the attribution partly unknowable; the row says what survives. |

## Process rules (adopted 2026-09-17 evening)

1. Analyst writes the claim + script + numbers (MEASURED → REPRODUCED).
2. A separate fresh context gets only the raw logs and the claim phrased as something to refute; it must produce its own numbers (→ VERIFIED / WEAKENED / REFUTED).
3. Before the drop, the readout script for each armed change is written and committed with its pass/fail criteria (pre-registered). After the drop it is run before any narrative is written.
4. Each armed change carries exactly one grep tag so the readout can attribute outcomes.
5. At most three behavioural changes armed per drop; each with a kill-switch.

### Adversarial code review of the change set (2026-09-20, fresh context; notes in `logs/analysis_2026_09_18/review_code/`)
Verdict: **not blocking** — no traced path places a second order or buys more than Q. Six substantive findings, all fixed the same evening, each mutation-checked (7/7 mutants caught):
