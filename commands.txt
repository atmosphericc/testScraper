----------------------------------------------------------------
  HOW TO RUN
----------------------------------------------------------------

  Production (what you actually launch):
    run_bot_with_nightly_restart.bat
    → The crash-restart wrapper. Arms every env flag, relaunches on
      crash, and restarts nightly. Launch it EXACTLY ONCE.
    → Dashboard: http://localhost:5001/v2

  Production, bare (no wrapper — flags are NOT armed):
    USE_RESILIENT_STACK=1 python app.py   → http://localhost:5001/v2

  Test env (stops before the real purchase):
    python test_app.py                    → http://localhost:5001/

  RULE: never launch the bot unprompted, and never run two instances
  at once — two concurrent app.py instances burned the whole 16-IP
  sweep pool to 100% captcha on 2026-09-04.

----------------------------------------------------------------
  SESSION SETUP (before a drop window)
----------------------------------------------------------------

  Hand-login all accounts:
    hand_login_all.bat
    → Opens a browser per account; sign in manually. Scripted relogin
      is Shape-burned (~0/25), so hand-login is the only path.

  Verify readiness (want 3/3 MEMBER):
    python check_session_readiness.py

  Restart the wrapper nightly — never let it run past 24h. Login
  sessions rot at 32-46h.

----------------------------------------------------------------
  STANDALONE TOOLS (no browser, no automation)
----------------------------------------------------------------

  Product config manager:
    python configureProducts.py    → http://localhost:5002/
    → Edit Target TCINs + catalog without starting a browser

  Pokemon price comparison:
    python compareInventory.py     → http://localhost:5003/
    → Compare CSV inventory against TCGdex/TCGPlayer market prices

  Kill a stuck port:
    python clearPort.py <port>

----------------------------------------------------------------
  TESTS
----------------------------------------------------------------

  Offline suite (the gate — 26 files, ~3.5 min):
    python tests/run_offline_suite.py

  NEVER blanket-run tests/ — it contains live tests that launch
  browsers and can fire real purchases. Use the suite runner.

  Resilient-stack smoke (live traffic, uses real proxies):
    RESILIENT_TEST_DURATION_S=120 RESILIENT_TEST_NUM_IPS=1 python test_resilient_stack.py
    python test_resilient_stack.py     (default 30 min)

----------------------------------------------------------------
  CONFIGURING PRODUCTS
----------------------------------------------------------------

  → Dashboard at http://localhost:5001/v2, or configureProducts.py,
    or edit config/product_config.json directly.
  → Field: "tcin" (8-10 digit Target item number from the URL)
  → Example: target.com/p/-/A-94724987 → tcin = "94724987"

  config/product_config.json fields:
    "tcin"      required  8-10 digit Target item ID
    "name"      required  display name
    "enabled"   required  true/false
    "priority"  required  1 = highest priority (checked first)
    "url"       optional  direct product link

  Commit arming/config changes BEFORE switching branches (08-18).
