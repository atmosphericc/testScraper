----------------------------------------------------------------
  HOW TO RUN
----------------------------------------------------------------

  python unified_app.py
  Unified dashboard  →  http://localhost:5000/dashboard    ← USE THIS

----------------------------------------------------------------
  SESSION SETUP (do this before first run)
----------------------------------------------------------------

  Target login:
    python relogin.py
    → Opens browser, log in manually, saves to nodriver-profile/ + target.json
    → Re-run when Target session expires

  Walmart login:
    python walmart_relogin.py
    → Opens browser, log in manually, saves to walmart-profile/cookies.json
    → Re-run when Walmart session expires

----------------------------------------------------------------
  STANDALONE APPS (debug / one-off use)
----------------------------------------------------------------

  Standalone Walmart only:
    python -m walmart.walmart_app  → http://localhost:5001/

  Standalone Target only:
    python app.py                  → http://localhost:5001/

  Target test mode (stops before purchase):
    python test_app.py             → http://localhost:5001/

  Product config manager (no automation):
    python configureProducts.py    → http://localhost:5002/
    → Edit Target TCINs + catalog without starting a browser

  Pokemon price comparison:
    python compareInventory.py     → http://localhost:5003/
    → Compare CSV inventory against TCGPlayer market prices

----------------------------------------------------------------
  DEBUGGING / ONE-SHOT CHECKS
----------------------------------------------------------------

  Check Walmart stock (all configured SKUs):
    python -m walmart.stock_monitor

  Kill a stuck port:
    python clearPort.py <port>
    → e.g. python clearPort.py 5000

----------------------------------------------------------------
  CONFIGURING PRODUCTS
----------------------------------------------------------------

  Target products:
    → Use dashboard at http://localhost:5000/dashboard (Product Catalog tab)
    → Or use standalone config tool: python configureProducts.py
    → Or edit config/product_config.json directly
    → Field: "tcin" (8-10 digit Target item number from URL)
    → Example: target.com/p/-/A-94724987 → tcin = "94724987"

  Walmart products:
    → Use dashboard at http://localhost:5000/dashboard (Walmart tab)
    → Or edit walmart/walmart_config.json directly
    → Field: "item_id" (numeric ID from walmart.com/ip/.../XXXXXXXXX)
    → Example: walmart.com/ip/some-product/15042474261 → item_id = "15042474261"

  Product config fields:
    Target (config/product_config.json):
      "tcin"      required  8-10 digit Target item ID
      "name"      required  display name
      "enabled"   required  true/false
      "priority"  required  1 = highest priority (checked first)
      "url"       optional  direct product link

    Walmart (walmart/walmart_config.json):
      "item_id"   required  numeric Walmart item ID
      "name"      required  display name
      "enabled"   required  true/false
      "priority"  required  1 = highest priority
      "max_price" optional  skip if price exceeds this
      "url"       optional  direct product link

----------------------------------------------------------------
  SET THESE ENV VARS BEFORE RUNNING
----------------------------------------------------------------

  Mac (Terminal):
    export WALMART_EMAIL="your@email.com"
    export WALMART_PASSWORD="yourpassword"
    export WALMART_CVV="123"
    export TARGET_CVV="123"
    export CHECKOUT_MODE="TEST"           # change to PRODUCTION when ready
    export FINAL_PURCHASE="NO"            # change to YES to actually buy

  Windows (PowerShell):
    $env:WALMART_EMAIL    = "your@email.com"
    $env:WALMART_PASSWORD = "yourpassword"
    $env:WALMART_CVV      = "123"
    $env:TARGET_CVV       = "123"
    $env:CHECKOUT_MODE    = "TEST"
    $env:FINAL_PURCHASE   = "NO"

----------------------------------------------------------------
  SAFETY CHECKLIST — before going LIVE
----------------------------------------------------------------

  1. Set CHECKOUT_MODE=PRODUCTION
  2. Set FINAL_PURCHASE=YES
  3. Set WALMART_CVV and TARGET_CVV to your actual card CVVs
  4. Confirm saved shipping address on Target.com and Walmart.com
  5. Confirm saved payment method on both accounts
  6. Run relogin.py + walmart_relogin.py to ensure fresh sessions
  7. Make sure the computer WON'T sleep (unified_app handles this,
     but double-check System Settings → Displays/Energy on Mac,
     or Power & Sleep on Windows)
